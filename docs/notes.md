# Ideas not yet adopted

The current open suggestion register, evidence, and test conditions are in [Scout: current state, audit findings, and open work](project-synthesis.md#unimplemented-work-in-priority-order). The original 28 September notes are preserved unchanged in [the archive](archive/notes-2026-09-28.md).

Ideas that remain unmeasured include cache prewarming, speculative page prefetch using only Scout's own fetcher, simple source/passage relevance ranking, a dated external-API usage-policy inventory, perspective-guided outlines for broad reports, bounded scholarly citation traversal, and evaluation-only stable retrieval. The [synthesis](project-synthesis.md) explains when each is worth testing and what would count as improvement. Restoring history trimming and adding CORE as a new integration are no longer open ideas; trimming was removed and CORE is already supported.

A proposal becomes a workflow change only after a concrete bottleneck, an offline regression check, and, where quality or cost is at stake, a predeclared paid study under [AGENTS.md](../AGENTS.md). A new run role still needs the user's approval in a plan.
